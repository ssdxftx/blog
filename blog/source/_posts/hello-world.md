欢迎来到我的博客！这是第一篇文章，用于验证站点搭建与主题配置是否正常。

## 快速开始

### 新建文章

```bash
$ hexo new "文章标题"
```

更多说明见 [写作](https://hexo.io/docs/writing.html)。

### 本地预览

```bash
$ hexo server
```

更多说明见 [服务器](https://hexo.io/docs/server.html)。

### 生成静态文件

```bash
$ hexo generate
```

更多说明见 [生成](https://hexo.io/docs/generating.html)。

### 部署到远程

```bash
$ hexo deploy
```

更多说明见 [部署](https://hexo.io/docs/one-command-deployment.html)。
